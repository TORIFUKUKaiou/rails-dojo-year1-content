# Stretch：第9回の問題でRuby文法を総復習する

Railsアプリケーションの処理は、Rubyで書かれています。

Railsの操作が終わったら、第9回Stretchへ進み、これまでに学んだRubyの文法を復習しましょう。

## 取り組み方

次の教材を開いてください。

- [第9回 Stretch：Rubyのパーツを組み合わせて、さらに先へ進もう](../09/stretch.md)

第9回Stretchでは、次の内容をまとめて復習できます。

- 計算と条件分岐
- 配列とハッシュのデータ処理
- メソッドで処理を整理する
- クラスで状態を管理する
- 検索や生成AIも使うチャレンジ課題

問題ごとに`stretch01.rb`、`stretch02.rb`のようなファイルを作り、実行結果を確認しながら進めてください。

```bash
ruby stretch01.rb
```

表示例がある問題では、実行結果と表示例を比べてください。

解答例を見る前に、まず自分でコードを書いて実行します。動いた後で解答例を開き、自分のコードとの違いを確認してください。
