### 💎 A. Ruby基礎：変数・演算（問1〜問4）

#### 問1
次のRubyプログラムを実行した際、ターミナルに出力される値はどれですか？
```ruby
x = 10
y = 5
x = x + y
y = x - y
puts y
```
1. `5`
2. `10`
3. `15`
4. `20`
* **解答**：2
* **解説**：3行目で `x` は `10 + 5` で `15` になります。4行目で `y` は `15 - 5` で `10` になり、それを出力します。

#### 問2
次のRubyプログラムを実行した際、出力される結果はどれですか？
```ruby
name = "Tom"
puts "Hello, #{name}"
puts 'Hello, #{name}'
```
1. `Hello, Tom` が2行出力される。
2. `Hello, #{name}` が2行出力される。
3. 1行目に `Hello, Tom`、2行目に `Hello, #{name}` が出力される。
4. エラー（Syntax Error）が発生して起動しない。
* **解答**：3
* **解説**：ダブルクォーテーション `""` で囲まれた文字列内では式展開（`#{}`）が有効になりますが、シングルクォーテーション `''` の中では式展開されず、そのままの文字列として出力されます。

#### 問3
次のRubyプログラムを実行した際、変数 `result` の中身はどうなりますか？
```ruby
a = 10
b = 3
result = a / b
```
1. `3`
2. `3.333333...`
3. `3.0`
4. エラーになる
* **解答**：1
* **解説**：Rubyにおいて、整数（Integer）同士の割り算の計算結果は小数点以下が切り捨てられ、整数になります。小数点数を取得したい場合は、どちらかを `10.0` のように浮動小数点数にする必要があります。

#### 問4
次のRubyプログラムを実行した際、出力される結果はどれですか？
```ruby
x = 5
x = x + 10
x = x * 2
puts x
```
1. `15`
2. `25`
3. `30`
4. `35`
* **解答**：3
* **解説**：`x = x + 10` で `15` になり、その後 `x = x * 2` で `15 * 2` となり `30` になります。

### ⚖️ B. Ruby基礎：条件分岐（問5〜問8）

#### 問5
次のRubyプログラムを実行した際、出力される文字はどれですか？
```ruby
score = 80
if score >= 60
  puts "C"
elsif score >= 80
  puts "B"
else
  puts "A"
end
```
1. `A`
2. `B`
3. `C`
4. `B` と `C` の両方
* **解答**：3
* **解説**：条件分岐は上から順に評価され、最初に合致したブロック（`score >= 60`）が実行されると残りの `elsif` や `else` は無視されます。80点は60点以上でもあるため、"C" が出力されます。

#### 問6
次のRubyプログラムを実行した際、出力される結果はどれですか？
```ruby
age = 18
is_member = false

if age >= 18 && is_member
  puts "入場可能（割引あり）"
elsif age >= 18 || is_member
  puts "入場可能（通常料金）"
else
  puts "入場不可"
end
```
1. 入場可能（割引あり）
2. 入場可能（通常料金）
3. 入場不可
4. エラーになる
* **解答**：2
* **解説**：`&&`（かつ）は両方が真である必要があり、`||`（または）はどちらか一方が真であれば成立します。今回、年齢は18以上なので `age >= 18 || is_member` が真となり、通常料金が出力されます。

#### 問7
次のプログラムを実行した際、出力される結果はどれですか？
```ruby
x = nil
if x
  puts "データがあります"
else
  puts "データがありません"
end
```
1. データがあります
2. データがありません
3. 何も表示されずに終了する
4. エラー（NoMethodError）になる
* **解答**：2
* **解説**：Rubyにおいて、`false` と `nil` は「偽」として扱われ、それ以外のすべてのオブジェクトは「真」として扱われます。したがって、`else` のブロックが実行されます。

#### 問8
次の条件式において、結果が「真（true）」になるものはどれですか？
1. `10 != 10`
2. `"apple" == "Apple"`
3. `!true`
4. `not (5 > 10)`
* **解答**：4
* **解説**：1は偽（10と10は等しい）、2は偽（大文字小文字は区別される）、3は偽（trueの否定なのでfalse）、4は「5は10より大きい」が偽（false）であり、それを否定（not）しているので真（true）になります。

### 🔁 C. Ruby基礎：繰り返し（問9〜問12）

#### 問9
次のプログラムを実行した際、出力される結果はどうなりますか？
```ruby
sum = 0
3.times do |i|
  sum += i
end
puts sum
```
1. `3`
2. `6`
3. `0`
4. エラーになる
* **解答**：1
* **解説**：`times` ループのブロック変数 `i` は `0` から始まります。つまり、`i` は `0, 1, 2` と変化するため、`0 + 1 + 2 = 3` になります。

#### 問10
次のプログラムを実行した際、どのような挙動になりますか？
```ruby
sum = 0
[1, 2, 3].each do |num|
  sum += num
end
puts num
```
1. `3` が出力される。
2. `6` が出力される。
3. エラー（NameError: undefined local variable or method `num'）が発生する。
4. 何も表示されずにプログラムが終了する。
* **解答**：3
* **解説**：`each` のブロック変数 `num` は、`do ... end` のブロック内部だけで有効なローカル変数です。ブロックの外で `puts num` と呼び出すと、変数が存在しないためエラーになります。

#### 問11
次のプログラムを実行した際、出力される結果はどれですか？
```ruby
numbers = [1, 2, 3, 4, 5]
new_numbers = []

numbers.each do |n|
  if n % 2 == 0
    new_numbers << n * 10
  end
end

p new_numbers
```
1. `[2, 4]`
2. `[10, 20, 30, 40, 50]`
3. `[20, 40]`
4. `[10, 30, 50]`
* **解答**：3
* **解説**：配列から偶数（`n % 2 == 0`）である `2` と `4` を取り出し、それぞれを10倍にした値（`20`, `40`）を空の配列 `new_numbers` に追加（`<<`）しています。

#### 問12
次のプログラムを実行した際、出力される結果はどれですか？
```ruby
count = 0
[1, 2, 3].each do
  count += 1
end
puts count
```
1. `0`
2. `1`
3. `3`
4. エラーになる
* **解答**：3
* **解説**：ブロック変数（`|i|` など）を使わなくても、配列の要素数（3つ）の分だけ繰り返しが実行されるため、`count` は 3 になります。

### 📦 D. Ruby基礎：配列（問13〜問16）

#### 問13
次のRubyプログラムを実行した際、出力される値はどれですか？
```ruby
numbers = [10, 20, 30]
puts numbers[3]
```
1. `30`
2. エラー（IndexOutOfBoundsError）が発生する。
3. 改行（何も表示されない / nil）が出力される。
4. `0`
* **解答**：3
* **解説**：Rubyの配列では、要素数を超えるインデックス（配列は0から始まるため、3番目は4つ目の要素）を指定すると、エラーにならずに `nil`（何もない状態）が返されます。

#### 問14
配列 `words = ["red", "blue", "green"]` に、新しい要素 `"yellow"` を末尾に追加するためのコードとして、**誤っているもの**はどれですか？
1. `words << "yellow"`
2. `words.push("yellow")`
3. `words[3] = "yellow"`
4. `words.add("yellow")`
* **解答**：4
* **解説**：Rubyの配列クラス（Array）には `.add` というメソッドは定義されていません（エラーになります）。

#### 問15
次のRubyプログラムを実行した際、出力される値はどれですか？
```ruby
data = [10, 20, 30, 40]
puts data.length
```
1. `4`
2. `3`
3. `40`
4. `10`
* **解答**：1
* **解説**：`length`（または `size`）メソッドは、配列の要素の数を返します。

#### 問16
次のプログラムを実行した際、出力される結果はどれですか？
```ruby
data = [1, 2, 3]
data[0] = 100
p data
```
1. `[100, 2, 3]`
2. `[1, 2, 3, 100]`
3. `[100, 1, 2, 3]`
4. エラーになる
* **解答**：1
* **解説**：`data[0] = 100` は、配列の0番目（最初の要素）の値を `100` に書き換える代入操作です。

### 🔑 E. Ruby基礎：ハッシュ（問17〜問20）

#### 問17
ハッシュのキーとして「シンボル（Symbol）」を使用した、正しいハッシュの書き方はどれですか？
1. `user = { "name" = "Tom", "age" = 20 }`
2. `user = { :name => "Tom", :age => 20 }`
3. `user = { name: "Tom", age: 20 }`
4. 2 と 3 の両方
* **解答**：4
* **解説**：シンボルをキーにする場合、古い書き方（`:name => "Tom"`）とモダンな書き方（`name: "Tom"`）のどちらも有効で、内部的には同じシンボルキーとして扱われます。

#### 問18
次のプログラムを実行した際、出力される値はどれですか？
```ruby
user = { "name" => "Tom", :name => "Bob" }
puts user[:name]
```
1. `Tom`
2. `Bob`
3. 両方出力される
4. エラーになる
* **解答**：2
* **解説**：文字列のキー `"name"` とシンボルのキー `:name` は、ハッシュの中では明確に別のキーとして区別されます。`user[:name]` で取得できるのはシンボルに対応する `"Bob"` です。

#### 問19
次のプログラムを実行した際、出力される値はどれですか？
```ruby
data = [
  { name: "Tom", hobby: ["baseball", "soccer"] },
  { name: "Bob", hobby: ["music"] }
]
puts data[0][:hobby][1]
```
1. `Tom`
2. `baseball`
3. `soccer`
4. `music`
* **解答**：3
* **解説**：`data[0]` は最初のハッシュ、その中の `[:hobby]` は配列 `["baseball", "soccer"]` を指し、そのインデックス `[1]`（2番目の要素）である `"soccer"` を取得しています。

#### 問20
ハッシュ `user = { name: "Alice", age: 25 }` に、新しいキーと値のペアとして `hometown: "Tokyo"` を追加する正しいコードはどれですか？
1. `user.add(hometown: "Tokyo")`
2. `user << { hometown: "Tokyo" }`
3. `user[:hometown] = "Tokyo"`
4. `user.push(:hometown, "Tokyo")`
* **解答**：3
* **解説**：ハッシュに値を追加・更新する際は、`ハッシュ名[キー] = 値` の代入構文を使用します。

### 🛠️ F. Ruby基礎：メソッドとクラス（問21〜問26）

#### 問21
次のプログラムを実行した際、出力される値はどれですか？
```ruby
def calc(x)
  x * 2
  x + 5
end

puts calc(10)
```
1. `20`
2. `15`
3. `20` と `15` の両方
4. エラーになる
* **解答**：2
* **解説**：Rubyのメソッドは、明示的な `return` がない場合、メソッド内で**最後に評価された式の値**が自動的に戻り値になります。ここでは `x + 5`（`10 + 5`）が最後の式であるため、`15` が返されます。

#### 問22
次のプログラムを実行した際、出力される値はどれですか？
```ruby
def greet(name = "Guest")
  return "Hello, #{name}"
end

puts greet
```
1. `Hello, Guest`
2. `Hello, `（名前の部分が空欄になる）
3. 引数エラー（ArgumentError）が発生する。
4. エラー（NameError）になる。
* **解答**：1
* **解説**：メソッドの引数定義で `name = "Guest"` としているのはデフォルト値（引数が渡されなかった場合に使われる初期値）の設定です。引数なしで `greet` を呼び出すと `"Guest"` が使われます。

#### 問23
メソッドの定義（`def`）と呼び出しに関する説明として、**誤っているもの**はどれですか？
1. メソッド内で定義した変数（ローカル変数）は、メソッドの外からは参照できない。
2. メソッドは呼び出される前に、プログラム内で定義されている必要がある。
3. メソッドの引数の数は、呼び出し時に渡す値の数と一致していなければならない（デフォルト値がある場合を除く）。
4. メソッドの戻り値は、必ず `return` を記述しなければ取り出せない。
* **解答**：4
* **解説**：問21の解説の通り、Rubyでは最後に評価された式の結果が自動的に戻り値になるため、`return` は必須ではありません（メソッドを途中で終了させたい場合などに使われます）。

#### 問24
次のプログラムを実行した際、どのような挙動になりますか？
```ruby
class User
  def initialize(name)
    @name = name
  end
end

user = User.new("Alice")
puts user.name
```
1. `Alice` が出力される。
2. 何も出力されずに終了する。
3. エラー（NoMethodError: undefined method `name'）が発生する。
4. エラー（ArgumentError）が発生する。
* **解答**：3
* **解説**：`@name` はインスタンス変数であり、クラスの外部から直接読み書きすることはできません。クラス外からアクセスするためには、ゲッターメソッド（例：`def name; @name; end`）を定義するか、`attr_reader :name` をクラス内に記述する必要があります。

#### 問25
クラスの設計図において、`def initialize` という名前のメソッド（初期化メソッド）が実行されるタイミングはいつですか？
1. プログラムが起動した直後。
2. クラス内に新しいメソッドが定義されたとき。
3. `クラス名.new` によって、新しいインスタンスが生成されたとき。
4. インスタンスがメモリから削除されたとき。
* **解答**：3
* **解説**：`initialize` メソッドは、クラスのオブジェクト（インスタンス）が `new` で作成される際に自動的に呼び出される特殊なメソッドです。

#### 問26
次のプログラムを実行した際、出力される結果はどれですか？
```ruby
class Counter
  def initialize
    @count = 0
  end

  def increment
    @count += 1
  end

  def show
    puts @count
  end
end

c = Counter.new
c.increment
c.increment
c.show
```
1. `0`
2. `1`
3. `2`
4. エラーになる
* **解答**：3
* **解説**：インスタンス変数 `@count` はオブジェクトごとに個別に維持されます。`increment` メソッドを2回呼び出したため、`@count` は `0 ➔ 1 ➔ 2` と加算され、`show` で `2` が出力されます。

### 🌐 G. Webの仕組み（問27〜問28）

#### 問27
ブラウザからサーバーへのHTTPリクエストにおいて、パスワードや個人情報などの「サーバー側のデータを書き換え・登録するデータ」を送信する際、最も適したHTTPメソッドはどれですか？
1. `GET`
2. `POST`
3. `DELETE`
4. `INDEX`
* **解答**：2
* **解説**：GETはデータを取得するためのメソッドであり、送信データはURLパラメータ（クエリストリング）としてURLに丸見えの状態で付与されます。データの新規追加やセキュリティが必要な情報の送信には `POST` を使用します。

#### 問28
Webの仕組みである「リクエスト」と「レスポンス」における記述として、正しいものはどれですか？
1. レスポンスを送るのはブラウザ（クライアント）であり、リクエストを送るのがWebサーバーである。
2. ブラウザがURLを指定してWebサーバーに要求を出すことを「リクエスト」、WebサーバーがHTMLなどのデータを送り返すことを「レスポンス」と呼ぶ。
3. データベース（SQLite3）がRailsアプリにデータを送る要求のことを「リクエスト」と呼ぶ。
4. 常にサーバーからブラウザに向けて、自動的・一方的にHTMLを送り続ける仕組みのことである。
* **解答**：2
* **解説**：クライアント（ブラウザ）からサーバーへの要求を「リクエスト（Request）」、それに対するサーバーからの返答を「レスポンス（Response）」と呼びます。

### 🚂 H. Railsの基礎（問29〜問30）

#### 問29
Railsアプリを作成するために `rails generate scaffold Memo title:string content:text` を実行しました。このとき生成されるファイルの構成に関する説明として、**誤っているもの**はどれですか？
1. `app/models/memo.rb` に、データベースのテーブル操作を担当するモデルクラスが生成される。
2. `app/controllers/memos_controller.rb` に、画面制御やデータ受け渡しを行うコントローラークラスが生成される。
3. `app/views/memos/` ディレクトリの中に、画面表示用のHTML.ERBファイル（ビュー）が複数生成される。

* **解答**：4
* **解説**：`scaffold` コマンドはプログラムのファイル群とマイグレーション（テーブル定義の指示書）を作成するだけで、実際のデータベースへの反映は行いません。必ず `rails db:migrate` コマンドを別途実行して反映させる必要があります。

#### 問30
Railsアプリで、URLとコントローラーのアクションを紐付ける定義が書かれているファイルはどれですか？
1. `config/database.yml`
2. `config/routes.rb`
3. `app/controllers/application_controller.rb`
4. `db/schema.rb`
* **解答**：2
* **解説**：リクエストされたURLのパスを解析し、どのアクション（処理）を実行するかを定義するルーティングファイルは `config/routes.rb` です。

## 🏁 第2部：実技試験「scaffoldアプリ構築タイムアタック」

### 🎯 ミッション要件
制限時間内に、Codespaces上で新規のRailsアプリを作成し、指定された仕様のscaffoldアプリを構築して、オシャレにカスタマイズした状態で起動しなさい。

#### 【条件】
- 講義資料、過去の演習ファイル、インターネット検索、生成AIの活用は**すべて自由**とします。
- 起動に成功したアプリのURL（CodespacesのプレビューURL）と、作成したファイルの内容を提出して評価します。

### 🛠️ 実技試験の実施ステップ（生徒用手順）

#### Step 1：Railsアプリの新規作成
1. ターミナルで次のコマンドを実行し、新しくRailsアプリを作成します。
   ```bash
   rails new my_memo_app
   ```
2. 作成されたアプリのディレクトリに移動します。
   ```bash
   cd my_memo_app
   ```

#### Step 2：scaffoldによるメモ機能の生成
1. 次の仕様に沿って、scaffoldで機能を生成します。
   * **モデル名（大文字開始・単数形）**：`Memo`
   * **属性（カラム）**：
     * タイトル：`title` （文字列型: `string`）
     * 本文：`content` （テキスト型: `text`）
   ```bash
   bin/rails generate scaffold Memo title:string content:text
   ```
2. データベースマイグレーションを実行し、データベースにテーブルを反映します。
   ```bash
   bin/rails db:migrate
   ```

#### Step 3：ビューのカスタマイズ（プチ・メイクアップ）
1. アプリケーションのタイトルを変更します。
   `app/views/memos/index.html.erb` を開き、ヘッダー（`<h1>`）にあるテキストを、**「（自分の名前）のメモ帳」** に変更して保存します。
2. 講義資料（第13週）で配布された「オシャレにするスタイル用CSS」のコードを、`app/assets/stylesheets/application.css` にコピー＆ペーストして保存します。

1. Railsサーバーを起動します。

3. **【提出物】**
   * 表示されたアプリのプレビューURL（例：`https://xxxxx-3000.app.github.dev/memos`）
   * カスタマイズした `app/views/memos/index.html.erb` のコード全体
