# Stretch：Railsの後にRubyの基礎を復習する

Practice が終わったら、Ruby の復習問題に進みます。

Railsでアプリケーションを作るときも、Rubyの基礎は何度も使います。

たとえば、scaffoldで生成されたファイルの中にも、変数、条件分岐、配列、ハッシュ、繰り返しに関係する考え方が出てきます。

## RailsとRubyをつなげて見る

Railsの画面では、1件のデータだけでなく、複数のデータを扱います。

たとえば、支出メモアプリで次のようなデータを登録したとします。

| Item | Amount | Category |
|---|---:|---|
| 昼食 | 850 | 食費 |
| ノート | 220 | 文房具 |
| 電車 | 320 | 交通費 |

このようなデータをRubyで考えると、ハッシュを配列に入れた形として表せます。

```ruby
expenses = [
  { item: "昼食", amount: 850, category: "食費" },
  { item: "ノート", amount: 220, category: "文房具" },
  { item: "電車", amount: 320, category: "交通費" }
]
```

合計金額を出すときは、配列を使って考えます。

```ruby
amounts = expenses.map do |expense|
  expense[:amount]
end

puts amounts.sum
```

表示例：

```text
1390
```

Railsの一覧画面も、考え方としては「複数のデータを取り出して、1つずつ表示する」処理につながっています。

## 取り組み方

第9回Stretchでは、問題ごとに `stretch01.rb`、`stretch02.rb` のようなファイルを作ります。

作成したRubyファイルは、次のコマンドで実行します。

```bash
ruby stretch01.rb
```

表示例がある問題では、実行結果と表示例を比べてください。

解答例を見る前に、まず自分でコードを書いて実行します。

動いた後で解答例を開き、自分のコードとの違いを確認してください。

## 復習するときの見方

第9回Stretchを解くときは、Railsとのつながりも意識します。

| Rubyの内容 | Railsでつながる場面 |
|---|---|
| 変数 | Controllerでデータを入れる |
| 条件分岐 | 入力内容によって表示や処理を変える |
| 配列 | 一覧画面で複数のデータを扱う |
| ハッシュ | 名前つきの値をまとめて扱う |
| 繰り返し | 複数のデータを1件ずつ表示する |
| `sum` | 金額などの合計を出す |
| `length` | 件数を数える |
| `min` / `max` | 一番小さい値・大きい値を探す |

Railsのコードをすべて読めなくても、Rubyの基礎がどこで使われそうかを考えながら進めます。
